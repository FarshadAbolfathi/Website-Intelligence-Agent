# API

## Public chat API

This is the contract the widget uses. Both editions implement it.

| | Self-Hosted | WordPress Lite |
|---|---|---|
| Base | `https://ENGINE/public/v1` | `https://SITE/wp-json/wia/v1` |
| Identification | `site_key` | not needed (`site_key` is ignored) |

### `POST {base}/chat`

```json
{ "site_key": "KEY", "message": "How much is Laptop A?", "conversation_id": null }
```

`message` is required and at most 1000 characters. Send back the `conversation_id` you receive to keep context.

```json
{
  "conversation_id": "abc123",
  "answer": "The price of “Laptop A” is 999 USD.\n(as of the site's last check on 2026-11-02)",
  "language": "en",
  "mode": "structured",
  "sources": [{ "url": "https://example.com/laptop-a", "title": "Laptop A", "checked_at": "2026-11-02T10:00:00+00:00" }],
  "stale": false
}
```

`mode` is one of:

| Mode | Meaning |
|---|---|
| `faq` | The owner's own answer |
| `structured` | Built from product data, no model involved |
| `llm` | Generated by the local model and passed verification |
| `extractive` | Quoted from the site's text |
| `not_found` | The site has no answer |
| `smalltalk` | Greeting or thanks |
| `guard` | Refused: an injection attempt or a request for secrets |

`stale: true` means volatile data could not be refreshed and may be out of date.

Errors: `404` unknown site key, `403` origin not allowed or assistant disabled, `422` or `400` invalid input, `429` rate limited (see `Retry-After`).

### `GET {base}/widget?site_key=KEY`

Returns display settings: `title`, `welcome`, `not_found`, `color`, `position`, `language`, `avatar_url`, `show_sources`, `enabled`.

## Admin API (Self-Hosted)

All routes need an authenticated session from `POST /api/auth/login`, and all are under `/api`.

| Route | Purpose |
|---|---|
| `GET /setup`, `POST /setup` | First-run state and admin creation |
| `POST /auth/login`, `POST /auth/logout`, `GET /auth/me` | Session |
| `GET /system/status` | Database, model, embedding and vector health; resources; job counts |
| `GET /models`, `POST /models/select`, `POST /models/pull` | Local models |
| `GET /jobs` | Background jobs |
| `GET, POST /sites` · `GET, PATCH, DELETE /sites/{id}` | Sites. `DELETE` erases all the site's data |
| `POST /sites/{id}/crawl` · `GET /sites/{id}/crawls` | Learning runs |
| `GET /sites/{id}/documents` · `DELETE /sites/{id}/documents/{doc}` | Knowledge base |
| `GET /sites/{id}/search?q=` | Inspect retrieval |
| `POST /sites/{id}/chat-test` | Try an answer, with full details |
| `GET, POST /sites/{id}/faqs` · `DELETE /sites/{id}/faqs/{faq}` | Owner's answers |
| `GET, POST /sites/{id}/competitors` · `DELETE .../{c}` · `POST .../{c}/crawl` | Competitors |
| `GET, POST /sites/{id}/competitor-reports` | Reports |
| `GET, POST /sites/{id}/evaluations` | Self-evaluation |
| `GET, DELETE /sites/{id}/conversations` · `GET .../{conv}` | Conversations |

With `WIA_ENV=development`, interactive documentation is at `/api/docs`.
